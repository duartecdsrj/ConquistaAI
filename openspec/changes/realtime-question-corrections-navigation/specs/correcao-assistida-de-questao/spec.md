## ADDED Requirements

### Requirement: Correção disponível em toda leitura de questão
O sistema SHALL disponibilizar a solicitação de correção no Banco de Questões e no Caderno.

#### Scenario: Solicitação no Banco de Questões
- **WHEN** o usuário abrir uma questão publicada no Banco de Questões
- **THEN** pode enviar instrução de correção para aquela questão
