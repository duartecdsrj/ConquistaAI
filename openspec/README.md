# OpenSpec — ConquistaAI

Idioma obrigatório: português do Brasil.

Use OpenSpec somente para mudanças de produto, arquitetura, banco, API, worker e interface. Correções pequenas, diagnósticos e documentação pontual não exigem proposta.

Contexto mínimo: leia primeiro `AGENTS.md`, `docs/ARCHITECTURE.md`, `docs/API.md`, `docs/FRONTEND.md` quando houver tela, e `docs/DEVELOPMENT_STATE.md`. Não replique essas regras em propostas.

Fluxo enxuto: `propose` cria proposta, especificação delta, decisão relevante e tarefas; `apply` lê somente os artefatos listados pelo CLI, executa uma tarefa por vez, valida e marca a tarefa; `archive` apenas após tarefas concluídas e atualização das specs principais.

Escreva requisitos verificáveis, decisões reversíveis e tarefas pequenas. Evite histórico, explicações óbvias, trechos duplicados e texto narrativo. Use links para arquivos existentes em vez de copiar conteúdo.
